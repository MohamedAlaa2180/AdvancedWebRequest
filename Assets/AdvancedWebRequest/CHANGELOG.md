# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-03

### Added
- Initial release of Advanced Web Request
- Core `ApiClient` with UniTask async/await support
- JWT authentication with `ITokenProvider` interface
- Automatic retry with exponential backoff and jitter
- Timeout control with cancellation support
- Structured error handling with `ApiException` and `ApiErrorResponse`
- JSON serialization/deserialization with Newtonsoft.Json
- Configurable logging with `ILogger` interface
- Fluent request builder API
- Request/response interceptor support
- Comprehensive examples and documentation

### Features
- ✅ Mobile and PC optimized
- ✅ Network error handling
- ✅ HTTP status code categorization
- ✅ CancellationToken support
- ✅ Parallel request support
- ✅ Token refresh example
- ✅ Custom retry policies
- ✅ Per-request timeout configuration
- ✅ Custom headers support
- ✅ Production-ready error model

### Documentation
- README.md with full feature documentation
- QUICKSTART.md for 5-minute setup
- Inline code examples
- Multiple example MonoBehaviours
- API usage patterns
